# DANK STREET — local preview

Self-contained static site for **dankstreetmusic.com**. Works on Mac and Windows.

Known issues and the update process live in **[BACKLOG.md](BACKLOG.md)**. Walk the sections below, then add anything new to the backlog before closing the session.

## Quick start

### Windows
Double-click `start-review.bat`, or:

```powershell
cd path\to\dank-street-site
python -m http.server 8080
# open http://127.0.0.1:8080
```

### Mac
Double-click `start-review.command`, or `python3 -m http.server 8080`.

## What to check

| Section | Look for |
|---------|----------|
| **Home** | Wordmark, 3D emblem, photo wash, Music / Tour / Book CTAs, Sound toggle |
| **Music** | Releases, embeds, Spotify / Apple / SoundCloud / Beatport links |
| **Tour** | Upcoming dates + ticket links + `.ics`; past shows under Recent |
| **Media** | Photo gallery + promo video |
| **Socials** | Instagram, Linktree, Spotify, SoundCloud, Apple Music, Beatport |
| **Merch** | Feature.fm waitlist CTA |
| **Contact** | About/bio, headshot, mailto, EPK download, booking form |

Live: https://dankstreetmusic.com/
