# DANK STREET — Website Review Draft

Draft official site for your review (not live yet). Self-contained static site — works on **Mac and Windows**, desktop and phone.

## Quick start

### Mac
1. Unzip this folder.
2. Double-click `start-review.command`  
   - First time: right-click → **Open** (Gatekeeper), or in Terminal: `chmod +x start-review.command`
3. Browser should open to `http://127.0.0.1:8080`

Or in Terminal:

```bash
cd /path/to/dank-street-site
python3 -m http.server 8080
# then open http://127.0.0.1:8080
```

### Windows
1. Unzip this folder.
2. Double-click `start-review.bat`
3. Browser should open to `http://127.0.0.1:8080`

Or in PowerShell / CMD:

```powershell
cd path\to\dank-street-site
python -m http.server 8080
# then open http://127.0.0.1:8080
```

**No Python?** Open `index.html` in Chrome, Safari, or Edge. Sound and some embeds may be limited via `file://`.

## Please also glance on your phone

Resize the browser or open the same URL on your phone (same Wi‑Fi / localhost tunnel if needed). Layout is tuned for ~375px phones and desktops.
