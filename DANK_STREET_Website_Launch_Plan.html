1. Summary

A working artist website has been built for DANK STREET, inspired by the immersive style of moodygood.com, with a blues / black / purple / white visual identity.

The site is a self-contained, modern static website (no complex backend). It includes:

  • Interactive home experience (drag-to-spin emblem, scramble title, optional ambient sound)
  • Music / releases section
  • Tour dates
  • Social links
  • Mailing-list signup
  • Contact (booking / management / press)

Next step: finalize your real content and assets, register a domain, deploy to hosting, and go live. A short 15-second site promo video has also been produced for socials once the URL is live.

D. Socials

G. Audio (optional but recommended)

  • Short ambient loop for the site sound toggle

H. Domain preference

  • Desired domain (e.g. dankstreet.com) and any backups if taken

4. Proposed Launch Plan

Phase 1 — Finalize the site (content & polish)
  1. Insert your content and assets into the site
  2. Connect streaming embeds and real links
  3. Wire mailing-list signup (or keep simple email fallback)
  4. Final review on desktop and mobile (all pages, sound, form)

Owner: Web team + DANK STREET (content delivery). Typical time: 1–3 days after content pack is received.

Phase 2 — Secure a domain
  1. Confirm preferred domain name
  2. Check availability and register (with WHOIS privacy)
  3. Prepare DNS for hosting

Owner: DANK STREET (purchase / ownership) or web team (guided setup). Typical cost: ~$10–20/year for a standard .com (varies by registrar).

Phase 3 — Hosting & HTTPS

Recommended: Cloudflare Pages (fast, free tier, automatic HTTPS, easy custom domain).

Alternatives: Netlify, Vercel, or GitHub Pages.

  1. Deploy the finished static site
  2. Confirm temporary preview URL works
  3. Attach custom domain and enable HTTPS
  4. Set www ↔ apex redirect as preferred

Owner: Web team. Typical time: same day once domain DNS is ready.

Phase 4 — Publish & announce
  1. Final production smoke test (pages, embeds, signup, contact, mobile)
  2. Update social bios / link-in-bio to the live URL
  3. Post the 15-second promo with the live link
  4. Optional: domain email (e.g. Cloudflare Email Routing or Google Workspace)

5. Technical Notes

  • Format: Static HTML / CSS / JavaScript — no app store, no server database required for the core site
  • Updates: Content is centralized; new releases/tour dates can be added without a full redesign
  • Hosting: Fits free or low-cost static hosting; scales with a CDN
  • Privacy / forms: Signup should use a reputable form or email provider you control
